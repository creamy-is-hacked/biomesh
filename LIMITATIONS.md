# Limitations

## M0 – Repository Bootstrap

- No biological model, numerical solver, cell model, parameter set, simulation
  output, renderer, or GUI is implemented.
- The command-line interface is a package-discovery shell only; it does not run
  simulations or accept scientific parameters.
- No biological parameter values, source citations, calibration, or benchmark
  results are supplied.
- License selection is pending.
- M0 is not accepted until the required checks, documentation review, and
  manual commit on `m0-repository-bootstrap` are complete.
